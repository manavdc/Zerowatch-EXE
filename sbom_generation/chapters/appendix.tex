% SBOM GENERATION
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

\section{SBOM Generation Command}

The Software Bill of Materials (SBOM) was generated using the Syft Software Composition Analysis (SCA) tool, scanning both the frontend and backend project directories:

\begin{verbatim}
syft dir:./frontend dir:./backend -o cyclonedx-json=zerowatch-sbom.json
\end{verbatim}

The generated CycloneDX SBOM served as the primary input for the vulnerability assessments performed using Grype and the ZeroWatch Audit Scan.

\vspace{0.4cm}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
% VULNERABILITY SCAN
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

\section{Vulnerability Assessment Command}

The generated SBOM and project dependencies were analyzed using the Grype Software Composition Analysis (SCA) tool and the proprietary ZeroWatch Audit Scan:

\begin{verbatim}
# Run Grype Vulnerability Scan
grype zerowatch-sbom.json -o json > zerowatch-grype-report.json

# Run ZeroWatch Audit Scan
node scan_sbom.js
\end{verbatim}

The resulting JSON report was used to generate the vulnerability findings presented in this report.
