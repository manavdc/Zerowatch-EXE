\section{Project Description}

\ProjectName\ is an endpoint security and monitoring agent designed to perform system telemetry, process audits, and security configuration analysis on client endpoints. The application continuously monitors host activities, enforces certificate pinning protocols, and updates its rules periodically.

The agent contains a local service module for background telemetry collection and a command-line utility for manual triggers, which communicate with the central administration platform.

To improve software supply chain security, the project generates a CycloneDX Software Bill of Materials (SBOM) using Syft and performs vulnerability assessment using Grype and the ZeroWatch Agent Scan. This enables complete visibility into software dependencies together with identification of known vulnerabilities and available security fixes.
